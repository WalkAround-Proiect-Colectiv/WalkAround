# Trip planning page

`TripPlanningScreen` is a single-page, mobile-first onboarding flow. Users explicitly search for and select GeoNames city suggestions, choose a local departure airport, enter budget, departure dates and times, nights, and ticket style, then inspect selectable flight cards on the same page. They can then search accommodations with the selected destination, staying nights, a separate accommodation budget, and a check-in date from the chosen flight or the calendar. Dates are chosen through `components/CalendarPicker.tsx`; budget, night count, and time fields strip nonnumeric input. Changing an input hides outdated offers. Flight cards expand to show every outbound and return segment and safe Google Flights links; accommodation cards show all returned property details, available booking options, and the separate property website when present. The page is available at `/trip-plan` and requires a signed-in session.
