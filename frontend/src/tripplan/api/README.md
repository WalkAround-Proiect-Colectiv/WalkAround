# Trip planning API client

`tripPlanning.ts` defines the JSON shapes used by the page and calls six trip-planning endpoints: city autocomplete, city airports, flight search, accommodation search, saved-plan creation, and tourist attractions. The attraction request uses the selected GeoNames destination's `lookupName` and `countryCode` in `GET /api/trip-plans/cities/{city}/attractions?countryCode=...&page=...`. It returns `PlaceRecommendationPage` with `items` and nullable `nextPage`; the next page is requested only on a user action. The accommodation request sends the selected destination city/country, first booked night, staying nights, and a separate full-stay EUR budget. Saved-plan creation sends the search preset, title, and optional description, but excludes check-in date and provider offers. The client URL-encodes city names and country codes, sends the current application JWT from the shared session module, applies a 90-second request timeout, and turns backend `ProblemDetail.detail` into a page error. It does not call GeoNames or SerpApi directly or store a token locally.
