# Trip planning API client

`tripPlanning.ts` defines the JSON shapes used by the page and calls five existing trip-planning endpoints: city autocomplete, city airports, flight search, accommodation search, and saved-plan creation. The accommodation request sends the selected GeoNames destination city/country, first booked night, staying nights, and a separate full-stay EUR budget. Saved-plan creation sends the search preset, title, and optional description, but excludes check-in date and provider offers. It URL-encodes city names and country codes, sends the current application JWT from the shared session module, applies a 90-second request timeout, and turns backend `ProblemDetail.detail` into a page error. It does not call GeoNames or SerpApi directly or store a token locally.
