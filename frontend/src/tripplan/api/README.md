# Trip planning API client

`tripPlanning.ts` defines the JSON shapes used by the page and calls four existing trip-planning endpoints: city autocomplete, city airports, flight search, and accommodation search. The accommodation request sends the selected GeoNames destination city/country, first booked night, staying nights, and a separate full-stay EUR budget. It URL-encodes city names and country codes, sends the current application JWT from the shared session module, applies a 90-second request timeout, and turns backend `ProblemDetail.detail` into a page error. It does not call GeoNames or SerpApi directly, store a token, or persist a search preset.
