# Map feature

`MapScreen` renders the map at `/map` using the platform-specific `MapCanvas` implementation. It loads the configured map style, adapts its resources in `style.ts`, and exposes preset locations, zoom, reset-north, and current-location controls. Pressing the location control requests foreground permission, centers on the current position, and starts a location watcher. Later presses recenter on the latest position without stopping the watcher. The watcher is removed when the map screen loses focus. Map loading and location failures stay visible on the map so users can retry.

The features menu is a floating control inside the map viewport at the top left. Pressing it opens a vertical panel directly below the button, over the map without changing its layout. **Explore map** closes the panel, **Plan a trip** opens `/trip-plan`, **Route Search** starts route selection, **Upcoming events** opens `/events` (passing the map centre as a fallback position; see [`src/events`](../events/README.md)), and **My future** is a disabled placeholder. The brand and account link remain in the header above the map.

The map connects to realtime dangerous-zone updates using `EXPO_PUBLIC_WS_URL` as the WebSocket service base URL, for example `ws://localhost:8083`. `MapScreen` appends `/ws/dangerous-zones` when opening the socket and removes any trailing slash from the configured base. For a physical device, use a reachable host rather than `localhost`.
